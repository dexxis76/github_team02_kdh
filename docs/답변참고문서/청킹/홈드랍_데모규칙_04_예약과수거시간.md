출처: # 홈드랍 데모 규칙 · ## 예약과 수거 시간
키워드: 예약 마감, 수거 시간, 출발 전날 수거, 기사 연락, 출발 시간대
## 예약과 수거 시간
- 예약 마감 : 출발 2일 전까지
- 수거 : 출발 전날(출발 1일 전)에 방문해 수거합니다. 희망 시각은 고객이 말합니다.
- 기사 연락 : 수거 30분 전
- 이용 가능한 출발 시간대 : 제1여객터미널 오전 11시~오후 11시, 제2여객터미널 오전 10시~오후 10시
- 항공편 정보를 확인할 수 있는 날짜 : 오늘부터 6일 뒤까지(운항 현황 API 제공 기간). 그 밖의 날짜는 확인 필요로 답합니다.
